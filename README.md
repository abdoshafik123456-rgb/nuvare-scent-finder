# NUVARE Scent Finder & E-Commerce Tools

An interactive web-based fragrance recommendation engine and digital storefront utility developed for **NUVARE**, an independent fragrance brand.

## Overview
Choosing the right fragrance online can be challenging. This project bridges the gap between physical scent profiles and online shopping by matching users with their ideal perfume or body splash based on preferred notes, occasion, and season.

## Key Features
- **Interactive Scent Quiz:** Recommends fragrances from the NUVARE collection (Rivora, Luvira, Vilvoura, Vidnight) based on user preferences.
- **Note Breakdown Visualizer:** Displays top, middle, and base notes for each fragrance.
- **Lightweight & Fast:** Built with clean HTML, CSS, and JavaScript for seamless integration with modern e-commerce platforms.

## Tech Stack
- HTML5 / CSS3 (Minimalist Dark & Gold Theme)
- Vanilla JavaScript (ES6+)
